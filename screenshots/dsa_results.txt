Linear search  : O(n)  - average 19.355 us, 799.0 comparisons per lookup
Dictionary     : O(1)  - average 0.064 us, 1.0 comparison per lookup
Dictionary lookup is about 304.5x faster on this dataset.

The comparison counts show the difference is structural, not just machine speed:
linear search walks the list until it finds the record, so its cost grows with the
record's position, while the dictionary hashes the key straight to its bucket and
does the same single probe no matter how large the dataset gets.
